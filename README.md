# Nirhalla Art Studio (Веб-интерфейс для Netlify)

Интерактивный веб-сервис для игроков, позволяющий загружать любые изображения с ПК и телефонов, выбирать размеры в блоках Майнкрафта (1x1, 2x2, 3x2 и т.д.), просматривать дизеринг в реальном времени и получать код картины для установки в игре.

---

## 🚀 Как задеплоить на Netlify за 30 секунд:

1. Зайди на [Netlify.com](https://app.netlify.com/) и войди в свой аккаунт (или зарегистрируйся бесплатно).
2. Перейди во вкладку **«Sites»**.
3. Внизу страницы найди область: **«Want to deploy a new site without connecting to Git? Drag and drop your site output folder here»**.
4. **Просто перетащи папку `nirhalla-art-web` мышкой в эту область!**
5. Netlify за 5 секунд опубликует сайт.

### 🌐 Как привязать свой домен `nirhalla.online`:
1. В настройках сайта в Netlify перейди в раздел **«Domain management»**.
2. Нажми **«Add a domain»** и введи: `nirhalla.online`.
3. Netlify покажет DNS-записи (обычно CNAME или A-запись `75.2.60.5`), добавь их у своего регистратора домена.
4. Бесплатный SSL-сертификат (HTTPS) выпустится автоматически через пару минут!

---

## 🎮 Возможности интерфейса:
- **Drag & Drop:** Перетаскивание файлов или выбор из галереи смартфона.
- **Вставка из буфера обмена:** Поддерживает `Ctrl+V`.
- **Живой Дизеринг Флойда-Стейнберга:** Прямо в браузере рассчитывает цвета в реальной палитре Майнкрафта.
- **Сетка блоков:** Игрок сразу видит, как картина делится на блоки на стене.
- **1-Click Копирование:** Генерация кода и готовой команды `/art <code>`.
